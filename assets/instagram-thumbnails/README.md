# Instagram portfolio thumbnails

Add one 16:9 JPG cover per Instagram item in this folder. Name each file with the reel or post ID, for example:

- `Dc0zx6WANxi.jpg`
- `DdQ0focFEYo.jpg`

The portfolio uses these files when present. Until then, each card shows its built-in fallback design. YouTube covers are loaded automatically from YouTube using the video ID.
